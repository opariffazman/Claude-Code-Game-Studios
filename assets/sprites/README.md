# Sprite Assets

## Required Downloads (all CC0 — no attribution needed)

### Kenney Particle Pack (future)
- URL: https://kenney.nl/assets/particle-pack
- 90 PNG sprites: circles, stars, sparks, smoke, fire
- License: CC0 1.0 Universal
- Usage: Destruction particles, impact effects, trails

### Kenney Game Icons (future)
- URL: https://kenney.nl/assets/game-icons
- 520 PNG icons: tools, objects, UI elements
- License: CC0 1.0 Universal
- Usage: Tool icons, desktop object icons

## Setup
1. Download packs from the URLs above
2. Extract particle PNGs to `assets/sprites/particles/`
3. Run `npm run build` to verify Vite bundles them
