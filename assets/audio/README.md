# Audio Assets

## Required Downloads (all CC0 — no attribution needed)

### Kenney Impact Sounds
- URL: https://kenney.nl/assets/impact-sounds
- 78 WAV files: glass, wood, metal, plastic impacts
- License: CC0 1.0 Universal
- Usage: Destruction effects, hammer hits, shatter sounds

### Kenney Interface Sounds
- URL: https://kenney.nl/assets/interface-sounds
- 251 WAV files: clicks, pops, whooshes, boings
- License: CC0 1.0 Universal
- Usage: Tool switching, UI feedback, keyboard sounds

## Setup
1. Download both packs from the URLs above
2. Extract to this directory (`assets/audio/sfx/`)
3. Run `npm run build` to verify Vite bundles them
