# Sprint 11 — 2026-03-30 to 2026-04-01 — Kenney Asset Pack Integration

## Sprint Goal

Replace all procedural Graphics-based desktop rendering with sprite-driven
themed desktops using Kenney CC0 atlas packs, validated end-to-end with the
animal-pack proof of concept before scaling to all 8 packs and 5 themes.

## Architectural Decisions (Finalized)

These decisions override ADR-001's original recommendations where they conflict:

| # | Decision | Source |
|---|----------|--------|
| 1 | **No hybrid rendering** — complete sprite replacement, remove Graphics fallback | User override of ADR-001 Decision 5 |
| 2 | **Sprite sheet atlases per pack** — TexturePacker or free-tex-packer-cli | ADR-001 Decision 1 |
| 3 | **On-demand loading** — lazy-load per theme, preload next in background | ADR-001 Decision 2 |
| 4 | **Assets in public/** — runtime loading, not Vite-bundled | ADR-001 Decision 3 |
| 5 | **ThemeSystem owns asset lifecycle** — no separate AssetManager | ADR-001 Decision 6 |
| 6 | **Animal-pack first** — proof of concept before generating all 8 atlases | User directive |

## Notes

- **ADR-001 Decision 5 overridden**: The ADR recommended keeping Graphics as a
  fallback. The user has decided to go all-in on sprites with no fallback. This
  simplifies code (one rendering path) but means missing textures will break
  rendering. The mitigation is rigorous texture key validation in S11-04 and S11-10.

- **Beads issue `desk-smasher-jsz` (texture-key manifest)** should be closed as
  superseded — the atlas generation script produces the manifest as a byproduct
  of atlas creation. No separate manifest task is needed.

- **Beads issue `desk-smasher-pnq` (sprite-based theme loader)** should be
  updated to reflect that ThemeSystem IS the loader. No separate ThemeLoader class.

- **Starting theme is `animal-farm`** per GDD section 5.2. This is also our PoC
  pack, so it gets the most validation.

- **Phase 1 is the hard gate**. If `Assets.load('sheet.json')` does not parse
  the atlas and register frame textures correctly in PixiJS 8, nothing else
  works. This must be validated before any other work proceeds.
